Висновки

Мій проєкт з 1 семестру — система плагінів. Є інтерфейс IPlugin і три класи: HelloPlugin, TimePlugin, ByePlugin. В Main вони створюються і виконуються в циклі.

Що вже є

Інтерфейс IPlugin вже є — це по суті Strategy, бо кожен плагін робить свою дію. DI/IoC частково теж є бо Main працює з інтерфейсом а не з конкретними класами напряму.

Чого не вистачає

Factory немає — плагіни створюються через new прямо в Main. Decorator немає — ніякого логування чи метрик. Observer немає — немає подій, все просто по черзі виконується.

Що зрозумів

Навіть в простому коді можуть бути елементи патернів. Інтерфейс IPlugin це вже Strategy. Але щоб код можна було легко розширювати треба ще прибрати new з Main і додати можливість логування через обгортку.
