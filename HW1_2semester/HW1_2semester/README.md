L01 — Самостійна робота

Какие паттерны использованы

1. DI/IoC (задача 1) — зависимость передаётся через конструктор, а не создаётся внутри класса.
2. Strategy + Factory (задача 2) — каждое правило в отдельном классе, фабрика собирает нужный набор.
3. Decorator (задача 3) — обёртка добавляет метрики поверх существующего правила без его изменения.
4. Observer (задача 4) — шина событий вместо прямых вызовов UI из бизнес-логики.

Какие проблемы решены

Классы не привязаны к конкретным реализациям — можно подменять зависимости.
Новые правила и подписчики добавляются без изменения существующего кода.
UI-логика отделена от бизнес-логики.

Что было сложнее всего

Задача 4 — нужно было продумать, как передавать разные данные через события, и правильно обработать сценарий с ошибкой.
